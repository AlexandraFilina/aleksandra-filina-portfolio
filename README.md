# Aleksandra Filina — Frontend Portfolio

Personal frontend portfolio for Aleksandra Filina, based in Valencia, Spain. The layout began as a Figma-to-code practice project and was adapted with original content, two live projects, professional experience, and responsive navigation.

**Live site:** https://aleksandra-filina-portfolio.vercel.app/

## Featured projects

- [Arandano Timer](https://arandano-timer.vercel.app/) — a focus timer with daily tasks and notes.
- [Self Lab](https://self-lab-six.vercel.app/) — a tool for personal habit experiments and check-ins.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm start
```

The development server runs at http://localhost:3000. Use `npm run build` to create the production build in `build/`.

## Tech

React, JavaScript, HTML, CSS, and Create React App. The featured projects use Next.js and TypeScript.
